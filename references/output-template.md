# 单题评审输出模板

每次单题评估按以下顺序输出，并在每项下区分“已有证据 / 分析推断 / 尚待验证”。

1. **选题基本信息**：原题、对象、场景、届次/组别、团队信息缺口。
2. **核心研究问题**：一句主问题、子问题、可测结果和决策主体。
3. **选题内在竞争力评分**：六维锚点、分项分、证据和 A 总分/状态。
4. **团队执行可行性评分**：五维锚点、分项分、证据覆盖度和 B 状态；无团队信息不补分。
5. **创新性分析**：问题、视角、机制、方法、场景、数据、应用七层对比。
6. **相似获奖论文对比**：来源等级、纸库 `paper_id`/页码或公共案例 URL；摘要与全文分开。
7. **调研设计建议**：总体、抽样框、样本量依据、问卷、访谈、预测试和偏差控制。
8. **研究方法推荐**：每个方法的作用、数据条件、风险和简单替代。
9. **数据获取与样本风险**：渠道、许可、代表性、非响应、时间和备选路径。
10. **一票否决风险检查**：不可完成、无渠道、不可测、设计根本缺陷、规则、伦理隐私。
11. **赛事规则适配情况**：版本、来源等级、适用组别、缺失文件和待核对项。
12. **相对获奖竞争力分析**：定性等级，不写概率，说明比较范围和限制。
13. **题目优化版本**：给出可验证的窄化题目和改写理由。
14. **下一步验证任务**：最少且可执行的预访谈、渠道确认、预测试或规则核验。
15. **最终立项建议**：建议立项/有条件立项/暂缓；列出必须先解决的事项。
