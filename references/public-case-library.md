# 2025—2026 公共案例索引

本索引来自工作区的公开补充包 `cases_2025_2026.csv` 与其来源目录。它保存题目、组别、奖项、学校、公开摘要、方法披露状态和来源 URL；公开摘要不是完整论文，未知字段不得补写。案例代表曾获奖或被公开报道，不代表同类题目当前仍有创新性。

## 使用边界

- A 级主办方文件优先；高校官网/官方媒体为 B 级；第三方图谱为 C 级检索入口。
- 只有题目而无摘要的记录只能用于主题检索，不能推断样本、模型或结论。
- 公共库不包含未经授权的完整论文、问卷、附件或个人联系方式。
