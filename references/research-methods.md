# 通用研究方法库

方法选择必须由研究问题和数据条件驱动。以下是选题评审时的最小判断表；私有论文索引只说明文本中出现过该术语，不能证明模型使用正确。

| 方法 | 解决什么问题 | 数据/条件 | 主要风险 | 简单替代 |
|---|---|---|---|---|
| 描述性统计 | 描述分布、画像和现状 | 清洗后的分类/连续变量 | 不能解释因果 | 频数、均值、分位数 |
| 交叉分析/卡方 | 比较分类变量关联 | 独立观测、合理期望频数 | 多重比较、样本偏差 | 分层比例与置信区间 |
| t 检验/方差分析 | 比较两组或多组均值 | 连续结果、独立性；必要时稳健检验 | 正态/方差假设和事后检验 | 中位数比较、Bootstrap |
| 相关分析 | 衡量变量共变 | 连续/有序变量、明确方向 | 相关不等于因果 | 散点图和分层比较 |
| 多元/Logistic 回归 | 估计因素与结果的关系/概率 | 足够样本、变量编码、诊断 | 混杂、共线性、过拟合 | 分层回归或简单比较 |
| 因子/主成分分析 | 降维和识别潜在维度 | 多题项量表、KMO/载荷检查 | 量表效度、旋转解释 | 理论维度汇总 |
| 聚类（K-means/K-modes） | 用户或场景分群 | 合适距离、标准化和稳定性 | 先验指定簇数、样本代表性 | 规则分层或决策树 |
| 结构方程模型 | 检验潜变量和机制路径 | 理论模型、量表、足够样本 | 模型识别、拟合指标滥用、因果过度解释 | 回归/路径分析 |
| 中介/调节 | 检验机制或条件差异 | 有明确时间/理论顺序 | 横截面数据的因果误读 | 分层回归与交互项 |
| IPA | 识别重要性与表现的优先级 | 同一指标的两类评分 | 量表端点和象限阈值任意 | 排序与缺口图 |
| TOPSIS/AHP/熵值法 | 多指标评价和排序 | 指标方向、权重依据、可比样本 | 权重主观、指标相关、伪精确 | 明确规则的加权评分 |
| 文本挖掘/爬虫 | 发现评论、舆情和主题 | 合法数据、清洗、抽样框 | 平台偏差、版权、隐私 | 人工编码小样本 |
| 离散选择/联合分析 | 估计属性与偏好的权衡 | 设计实验、属性水平、足够样本 | 任务负担、外部效度 | 概念测试或排序题 |
| 访谈/焦点座谈 | 探索概念、动机和语言 | 有目的抽样、提纲、编码 | 便利样本和研究者偏差 | 开放题或短访谈 |

## 组合原则

- “探索 → 测量 → 解释 → 决策”比堆叠模型更稳健。
- 需要因果时优先考虑实验、准实验或时间顺序；横截面问卷只能谨慎表述关联。
- 评价模型必须说明指标来源、权重敏感性和决策阈值。
- 涉及未成年人、健康、金融、位置或身份数据时，先做最小化收集、告知同意和脱敏。
