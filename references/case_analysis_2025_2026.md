# 2025—2026 正大杯公开获奖案例：选题分析

> 本文件基于高校官网、赛事承办高校报道及公开获奖信息整理。它是“公开摘要案例库”，不是完整论文阅读笔记。对来源未披露的方法、样本和数据，明确标记为未知，不作推断。

## 一、2025年第十五届：可观察到的选题路径

### 1. 企业需求与产品创新
- **《菜逢其时，预领未来》**：正大集团预制菜新产品市场调查，题目明确连接产品、消费者和行业。
- 启发：企业命题不应只做品牌满意度问卷。应研究细分客群、真实使用场景、购买阻力、产品机会和上市策略，最后能支持产品决策。

### 2. 银发经济与具体产品/服务
- **《智暖桑榆筑安巢，适老家居护健康》**：从适老化智能家居进入消费趋势、用户需求与政策应用。
- 启发：不要泛泛研究“老龄化问题”，而要具体到产品类别、使用者、购买决策者、付费者、使用障碍和服务场景。

### 3. 新兴内容产业与用户行为
- **《“短”线引力，“剧”像焕新》**：微短剧观看现状、群体画像、观看意愿机制。
- 启发：对热点内容产业，不能停留在“喜欢不喜欢”，应研究接触、使用、付费、持续使用、内容偏好和平台策略。

### 4. 情绪价值与体验营销
- **《触绒生情，软占心智》**：以Jellycat为例，使用SOR理论和结构方程模型研究体验营销、情感反应与购买意愿。
- 启发：把“情绪价值”拆成可测量的体验维度、情绪反应和行为结果，避免把抽象概念当作创新。

### 5. 地方文化与产业活化
- **牙舟陶、苗族刺绣、农创客基地**等研究生组公开赛案例。
- 启发：文化、非遗和乡村振兴类题目必须落到市场需求、消费转化、传承参与、运营机制或产业收益，不能只做文化介绍。

## 二、2026年第十六届：公开报道呈现的研究设计特征

### 1. 多源数据与实地调研
- **播客与Z世代注意力**：13个城市、2640份问卷、60场访谈，并通过自主运营播客做实践验证。
- **口袋公园**：230个公园场景，结合网络评论、分层抽样问卷和半结构化访谈。
- **县域充电设施**：舆情、实地勘测、访谈和问卷结合。
- 启发：高质量调研不只是问卷数量大，而是数据来源与研究问题匹配，能相互验证。

### 2. 从热点事件转向机制研究
- **苏超赛事经济**：不是只问“是否关注苏超”，而是研究赛事流量如何转化为消费增量，并分析政府、商户、观众三端协同。
- **Labubu潮玩消费**：标题从短期舆论爆款切入社群留存和消费机制。
- 启发：热点只是入口，真正的研究问题应该是机制、转化、持续性、异质性或政策/商业决策。

### 3. 具体场景与真实决策主体
- **AI滤镜**：聚焦功能趋同、需求分化、付费转化和数据合规，且对接企业需求。
- **酒店宅度假**：具体到客群、场景和酒店经营需求。
- **短托养老**：具体到城市服务市场和优化策略。
- 启发：尽可能把“研究对象—具体场景—关键决策—可执行建议”连成闭环。

### 4. 多主体协同与公共治理
- **城市公园、石库门更新、苏超赛事经济**均呈现多主体视角。
- 启发：当问题本身涉及公共服务或产业生态时，可考虑居民/消费者、运营者、企业、政府等主体之间的利益和行为关系。

### 5. 统计方法的使用原则
公开报道中出现了聚类、结构方程、随机森林、TOPSIS、AHP、ANOVA等方法，但这不意味着模型越多越好。
- 先明确研究问题和变量，再选择方法。
- 每种方法都要能解释“它解决哪个问题、需要什么数据、结果如何转化为结论”。
- Skill 不应根据获奖作品出现某个模型，就机械地给相似选题推荐该模型。
- 公开新闻摘要不足以评价这些模型在完整论文中的使用质量。

## 三、跨届次的共性观察（仅作为启发，不是官方评分标准）

1. **具体问题优于宽泛热点**：从“人工智能影响消费”收窄到某一产品、场景、群体和决策问题。
2. **现实需求优于概念包装**：企业痛点、公共服务痛点、区域产业痛点都可以成为切入点。
3. **机制研究优于现状罗列**：不仅描述现状，还解释为什么发生、哪些群体不同、如何干预。
4. **数据设计优于模型堆叠**：样本、抽样、测量、偏差控制和多源验证是基础。
5. **建议需要可执行**：结论应能对应企业产品、营销策略、公共服务或治理方案。
6. **地域不是创新本身**：换城市、换学校、换消费群体不自动构成创新；需要说明新场景产生了什么新问题或新机制。
7. **热点时效性需要审查**：赛事、IP、平台、政策等热点可能快速变化，必须重新验证调查窗口和研究价值。

## 四、给选题评审 Skill 的建议

对每个候选选题，至少做以下检验：
- 研究问题是否比标题更清晰？
- 研究对象、调查单位、目标总体和抽样框是否明确？
- 关键概念是否能操作化为变量或指标？
- 是否存在真实可行的数据获取路径？
- 是否有与已有研究/获奖案例不同的机制、情境、方法或决策价值？
- 是否能形成“问题—证据—分析—结论—建议”的闭环？
- 是否有必要做预访谈、预测试或小样本可行性验证？

## 五、不要从获奖案例推出的错误结论

- “某个领域去年获奖，所以今年做这个领域就有优势。”
- “某个一等奖用了SEM，所以我的题目也必须用SEM。”
- “题目很新潮，评委就会喜欢。”
- “调查了很多份问卷，就一定代表性强。”
- “有企业名称就代表有企业合作。”
- “新闻稿写了创新，不等于完整论文已经证明了创新。”

应把获奖案例作为对照材料，而不是选题模板。
